哈希表

用于快速判断一个元素是否在集合内。

通过牺牲空间提高时间效率，查找时间复杂度为O(1)，通过hashCode()函数将元素名称转化为特定的key进行映射，对于重名映射，会使用不同的再散列算法防止冲突。

常用于：统计频率，判断元素是否出现过等。

三种哈希结构

  • 数组

    相对简单，常见于统计字符串中元素的出现次数。

  • set

    集合，按序或无序存放内容，提供高效的查找、插入、删除等操作。

    集合与数组的顺序存储结构不同，数据存放位置与插入次序无关，且只能查询其中有无此种元素，以及增删。

    std::set：以红黑树实现的集合，元素有序，数值不可重复、不可更改其中元素值，查询效率与增删效率都为O(log n)。

    std::multiset：以红黑树实现的集合，元素有序，数值可以重复、不可更改其中元素值，查询效率与增删效率都为O(log n)。

    通过count(x)返回多重集合中x出现的次数。

    std::unordered_set：基于哈希表的集合，数据无序存放，数值不可重复、不可修改。查询效率与增删效率都为O(1)。

  • map

    映射，也称为字典，常见形式为<key, value>，即一个关键字对应一个值，关键字不可修改，但其对应值可修改。

    • std::map：基于红黑树实现，关键字不可重复、不可修改、按序存放，查询效率与增删效率均为O(log n)。

    • std::multimap：基于红黑树实现，关键字可重复、不可修改、按序存放，查询效率与增删效率均为O(log n)。

    • std::unordered_map：基于散列表实现，关键字不可重复、不可修改、乱序存放，查询效率与增删效率均为O(1)。

1. 两数之和

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target 的那 两个 整数，并返回它们的数组下标。 你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。 你可以按任意顺序返回答案。

示例 1： 输入：nums = [2,7,11,15], target = 9 输出：[0,1] 解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。 示例 2：

输入：nums = [3,2,4], target = 6 输出：[1,2] 示例 3：

输入：nums = [3,3], target = 6 输出：[0,1]

本体常规做法略过（时间复杂度O(n²)）。利用哈希表可以以O(n)的时间复杂度解决问题。

思路

当我们需要查询一个元素是否出现过、统计一个元素的出现频率，或者一个元素是否在集合内的时候，就要第一时间想到通过哈希表解决问题。

本题中，我们需要输出下标值，且需要知道下标值对应着的值有没有遍历过，故需要std::unordered_map进行<key, value>存储。

  1. 题目中给出target值，并且要求其为两个不同下标对应的值相加之和。
  2. 以第一个例子为例，nums[0] == 2，target == 9。由此，若0为某一结果对中下标之一的话，nums数组里就需要出现9 - nums[0]这个值。
  3. 由此出现了“查询某一元素是否在这个数组中”这一个需求，故使用哈希表法。并且，将值作为key，将对应下标作为value。

    注意：一般而言，比较key是否出现在某一集合才是正确选择，若比较value，则需要对map整体进行遍历，得不偿失。

  4. 对于遍历中的每一次比较，首先将target - nums[i]作为key尝试在map中查找并取其value，若成功取值，则在结果数组中插入{i, value}，否则，在map中插入{nums[i], i}这一键值对。

    通过尝试查找另一个数是否在此集合，并由此获得对应下标，会节省大量时间。

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int,int> res;
        vector<int> ret = {};
        for(int i = 0; i < nums.size(); i++)
        {
            auto it = res.find(target - nums[i]);
            if (it != res.end()){      // 若find没找到，则返回map.end();
                return {it->second, i};// 题意明确每次输入只对应一个答案
            }
            res[nums[i]] = i;          // 在map中插入键值对，map[key] = value;
        }
        return ret;
    }
};

49. 字母异位词分组

给你一个字符串数组，请你将字母异位词组合在一起。可以按任意顺序返回结果列表。

字母异位词是通过重新排列不同单词或短语的字母而形成的单词或短语，并使用所有原字母一次。

示例 1:

输入: strs = [“eat”, “tea”, “tan”, “ate”, “nat”, “bat”]

输出: [[“bat”],[“nat”,“tan”],[“ate”,“eat”,“tea”]]

解释：

在 strs 中没有字符串可以通过重新排列来形成 “bat”。 字符串 “nat” 和 “tan” 是字母异位词，因为它们可以重新排列以形成彼此。 字符串 “ate” ，“eat” 和 “tea” 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:

输入: strs = [""]

输出: [[""]]

示例 3:

输入: strs = [“a”]

输出: [[“a”]]

思路

  1. 输入元素为string，输出元素为vector<string>。
  2. 题目中的字母异位词，实质上告诉我们，每个输出元素中的单词中，字母、字母数量均保持一致。
  3. 由此可以想到，是不是可以使用这个特性，在map中设置<字符串，字符串数组>键值对，通过对每个字符串进行排序操作，同一组字母异位词化为一个“统一”的字符串，并以此为key，对应的value字符串数组存放每一个对应的字母异位词。

    本题中虽然涉及到元素出现次数统计，但是由于输入与输出结果都是对整个字符串而言，因而我们的map也要“升一个维度”，不能拘泥于单独某个元素的出现次数。

class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> map;  // 哈希字典
        vector<vector<string>> res;  // 结果数组
        for(auto& s:strs){ // 对每个strs中的字符串进行操作
            auto key = s;
            sort(key.begin(), key.end());  // 对临时字符串s进行排序，得到其每组字母异位词中“唯一”的key
            map[key].emplace_back(s);      // 对应插入
        }
        for(auto&i : map){  // 遍历字典，将所有key-value中的value插入到结果数组中，可以理解为“摘果子”
            res.emplace_back(i.second);
        }
        return res;
    }
};

128. 最长连续序列

给定一个未排序的整数数组nums，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为O(n)的算法解决此问题。

示例 1：

输入：nums = [100,4,200,1,3,2] 输出：4 解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

示例 2：

输入：nums = [0,3,7,2,5,8,4,6,0,1] 输出：9

示例 3：

输入：nums = [1,0,1,2] 输出：3

思路

  1. 输入为int[]，输出为int。

  2. 常规思路：排序（O(n²)），再遍历去找最长连续序列（O(n)）。

    此时时间复杂度变为O(n²)，不符合题意。

  3. 若要实现O(n)的复杂度，我们需要想，可不可以只遍历“1”次数组（即每次遍历数组时要从头到尾，不能回溯）。

  4. 并且，题目中不要求序列元素在原数组中连续，可以想到，只需要统计每个数字是否出现，并确定每个子序列的头，向下寻找，直到当前序列结束，统计该序列长度，最后对所有序列选取最大值即可。

  5. 由此，则可以利用std::unordered_set进行操作，在将数组元素全部放进集合后，对集合遍历。

    • 若set.count(i-1) == 1，则意味着此时的i不是某个序列头，继续遍历集合。

    • 若set.count(i-1) == 0，意味着此时的i是某个序列的第一个数字，此时循环查询集合中是否有i+k（k = 1,2,3…），并统计长度，直到某一次的查询失败为止。

为什么不用std::set？因为set每一次插入时间复杂度为O(logn)，此时整体的时间复杂度就会来到O(n logn)，与题意不符。

class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> sets;
        for(auto i : nums) // 数组元素放入集合中
        {
            sets.insert(i);  // 哈希集合插入时间复杂度为O(1)
        }

        int max_n = 0;
        for(auto i : sets){
            if(sets.count(i-1) == 1) 
                continue; // 代表着此时的i不是子序列的头

            else {// 此为序列打头
                int currentStr = 1;
                for(int index = i;;index++){  // 不断执行i+k，直到到达序列末尾
                    if(sets.count(index+1)) 
                        ++currentStr; // 有下一个数，就++
                    else{
                        break;
                    }
                }
                if (currentStr > max_n) max_n = currentStr; // 记录最大的子序列长度
            }
        } // 总体来看，这个for循环虽然是嵌套的，但是并没有回溯遍历，因此总的来说仍然是O(n)
        return max_n;
    }
};
